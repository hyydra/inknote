# Publish Pennino v0.4.20

- Goal: Ship the glyph-precise text-block activation the user asked for ("when the user won't click directly on a letter, don't activate text box") and release it.
- Owner: Qoder.
- State: Published. Tag `v0.4.20` at `010b2b5`, both assets live.

## Log

- User decision that shaped the change: taps inside a written block but off its glyphs behave like bare paper and draw; an empty block still opens anywhere in its frame.
- Three paths used to activate a block on any point inside its rectangle: `_textBlockAtViewport` rect containment, the block's translucent `GestureDetector`, and the `expands: true` `TextField` (which sits in the hit path before the canvas `Listener`, so the canvas alone cannot veto it).
- Fix: the rect hit-test became `_textBlockHitAt`, which lays the block out (`_layoutTextBlock`, shared with `_growTextBlockToFit` so the two cannot drift) and accepts only points inside a `computeLineMetrics()` line box; the block's `GestureDetector` is gone; the field subtree is wrapped in `IgnorePointer(ignoring: !(tool == DrawTool.text && activeTextIndex == index))`.
- Gating on the tool and the active index, not on `hasFocus`: `IgnorePointer` is built by the editor, so a focus change alone would not rebuild it, and a stale gate would freeze caret placement and text selection in the active block.
- `text wins over every drawing tool when tapped` encoded the old rule by tapping the block's centre; it now taps the glyph line and keeps its original intent.
- Ignoring the field for a non-active block silently took two things with it: the caret the field used to place, and `TextField.onTap`, which is what toggles an inline checklist mark. `_activateTextAt` now sets the selection from `getPositionForOffset` and calls `_toggleChecklistAtSelection` itself, but only when the field did not own the pointer, so drag-selection inside the active block still belongs to the field.
- Local verification on the bump: `flutter analyze` clean, `flutter test` +23, `widget_test/editor_gesture_test.dart` +34 (5 new specs: glyph tap opens, past-end-of-line draws, blank padding draws, empty block opens, checklist mark toggles on the first tap).

## Don't repeat

- Do not create `v0.4.20` before the post-merge `main` workflow passes, and never re-tag `v0.4.19`.
- Do not gate the block's pointer behaviour on `activeTextIndex` alone — `_selectTool` leaves it set after leaving the text tool.
- Do not upload local build artifacts; the release workflow signs with the configured Android secrets.
- Leave unrelated untracked `.codex/`, `reports/`, and `research_notes/` untouched.
